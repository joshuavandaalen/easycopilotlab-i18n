Build your team's dedicated AI without coding — master it in one day

## Why This Course Is Special

> *"Those who write great instructions build great agents. This isn't a STEM domain."*

An agent's quality is determined not by coding skill, but by **the quality of its instructions**.
Context understanding, writing, persuasion, storytelling — these are your strengths and the most important skills in Copilot Studio.

| Your Strength | Role in Copilot Studio |
|:------------|:------------------------|
| Context understanding | Designing role, scope, and principles for instructions |
| Writing | Crafting instruction and Topic text |
| Persuasion & communication | Designing agent tone and attitude |
| Storytelling | Designing conversation flows (Topics) |
| Domain expertise | Planning and organizing knowledge sources (documents) |

---

## Analogy System — These Are the Only Terms You Need

This course uses **familiar analogies** instead of unfamiliar technical terms.

| Concept | Analogy | One-line Description |
|:-----|:-----|:---------|
| Agent | 🧑‍💼 New hire | An AI employee that follows instructions |
| Instructions | 📋 Job posting | Defines the agent's role, attitude, and scope |
| Knowledge | 📚 Textbook | The materials the agent uses to base its answers on |
| Variable | 📝 Sticky note | Something noted during conversation to use later |
| Topic | 🎬 Script | The flow the agent follows in specific situations |
| Flow | 🤲 Hands & feet | What lets the agent take real actions |
| Email forwarding | ✉️ Envelope | Automatically forwards inquiries to the right person |
